# moon-walker

現在地と端末の向きを利用して、月がある方向を直感的に確認できるWebアプリです。

## Demo

https://moon-walker.vercel.app/

※現在開発中です

## 主な機能

- 現在地の取得
- ホーム画面で現在地の天気と雲量を表示（Open-Meteo）
- 月の位置計算
- 端末の向きの取得
- 月の方向表示
- センサーのキャリブレーション
- 月が地平線より下にある場合の表示
- センサー許可状態に応じた案内

## 技術スタック

- React
- TypeScript
- Vite
- Geolocation API
- DeviceOrientation API
- Vercel

## 天気情報

月が出ていないときに、ホーム画面の「天気を表示」から現在地の天気と雲量を確認できます。天気欄は必要なときに開き、普段はホーム画面をすっきり保ちます。天気は「晴れ」「曇り」「雨」など簡潔に表示します。月が地平線より上にある場合は、従来どおり準備画面へ自動で移動します。

[Open-Meteo Forecast API](https://open-meteo.com/en/docs) の現在の天気コードと雲量を利用し、位置情報取得後にブラウザーから緯度・経度を送信します。APIキーの設定は不要です。表示中は15分ごとに更新し、「天気を再取得」から手動更新できます。通信に失敗した場合はエラーを表示します。

天気は気象モデルの推定値です。対象時刻は日本時間で表示し、月の観測日時をテスト日時に固定していても天気は現在の情報を取得します。

## 次の特別な月

月情報ページで、満月・新月・ブルームーン・月食のうち次に起きるイベントを表示します。満月・新月と月食は Astronomy Engine のイベント検索APIを使い、月相の探索範囲は3年間です。ブルームーンは端末のローカル暦月で2回目に起きる満月と定義します。

今日起きるイベントがあれば、すでに起きた場合も今日のうちは優先して表示します。同じ日に重なる場合は月食を満月より優先し、それ以外は日時が最も早いイベントを表示します。イベント日時は端末のローカルタイムで表示します。

スーパームーンは統一された距離の閾値がないため、中秋の名月は旧暦への安全な変換機能がないため、初回実装では未対応です。月食は地球上で起きる時刻を示し、月食が見える地域は場所によって異なります。
